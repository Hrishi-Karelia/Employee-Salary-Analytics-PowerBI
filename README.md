# Employee-Salary-Analytics-PowerBI
Interactive Power BI dashboard analyzing employee compensation trends, salary distribution, percentile analysis, and workforce insights using DAX and data modeling.
Employee Salary Analytics Dashboard
Project Overview

This project is an interactive Power BI dashboard designed to analyze employee salary data across different departments, job categories, and employee groups. The dashboard provides insights into compensation trends, salary distribution, workforce analytics, and statistical salary measures to support data-driven HR and financial decision-making.

Business Problem

Organizations often struggle to analyze large employee compensation datasets efficiently. This project helps management and HR teams:

Monitor salary distribution across departments
Identify high and low compensation groups
Analyze workforce salary trends
Detect salary outliers and inconsistencies
Support compensation planning and benchmarking
